Student Performance Analysis – Exploratory Data Analysis (EDA)
## 1. Project Overview
The Student Performance Analysis project focuses on exploring student academic performance using Python. The objective is to analyze examination scores, identify patterns in student-related factors and generate meaningful insights that can help improve academic results.
## 2. Project Objectives
•	Load and preprocess the student performance dataset.
•	Analyse overall student examination performance.
•	Explore factors associated with academic performance, including study hours and attendance.
•	Compare examination performance across different student groups.
•	Create visualizations to identify patterns and trends.
•	Generate insights and recommendations for improving academic results.
## 3. Dataset Information
•	Dataset Name: Student Performance Factors
•	Total Records: 6,607
•	Total Columns: 20
•	Target Variable: Exam_Score
•	File Format: CSV
The dataset contains student information such as study hours, attendance, previous scores, sleep hours, parental involvement, internet access, family income, teacher quality, school type, gender and distance from home.

## 6. Exploratory Data Analysis
A. Overall Performance Analysis
Analysed the distribution of student examination scores and explored overall academic performance patterns.
B. Study Habits and Academic Performance
Explored the relationship between study hours, attendance, sleep hours and examination scores.
C. Student and Family Factors
Analyzed parental involvement, parental education, family income, motivation level and peer influence in relation to examination performance.
D. School and Learning Factors
Examined teacher quality, access to learning resources, tutoring sessions, internet access and school type.
E. Student Group Comparisons
Compared average examination scores across gender groups and distance-from-home categories.
